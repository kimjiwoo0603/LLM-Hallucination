# HALO 뉴스 검증 Agent (10분 토이 프로젝트)

뉴스 원문과 질문을 넣으면 세 단계로 처리합니다.

1. **작성 Agent**가 질문에 대한 답변 초안과 근거 후보를 만듭니다.
2. **검사 Agent**가 각 후보의 인용 근거와 의미 일치 여부를 확인합니다.
3. **수정 Agent**는 `SUPPORTED`인 항목만 사용해 최종 답변을 다시 만듭니다. 근거가 없으면 답변을 보류합니다.

## 가장 쉬운 실행 방법

Windows라면 우선 `start.bat` 파일을 더블클릭해 보세요. 필요한 준비를 하고 앱을 엽니다. 처음 한 번은 인터넷 연결이 필요합니다.

터미널로 실행하고 싶다면 이 폴더를 연 뒤 아래 두 줄을 순서대로 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

3. 브라우저가 열리면 뉴스 **원문 전체**를 붙여 넣고 `검증 시작`을 누릅니다.

질문에 자연스러운 답변을 만들고 검사 후 수정하는 전체 흐름을 보려면 왼쪽의 **OpenAI API로 질문 답변**을 켜고 API 키를 입력하세요.

## AI 작성 Agent를 쓰고 싶다면

1. OpenAI API 키를 준비합니다.
2. 화면 왼쪽에서 `OpenAI API 사용`을 켭니다.
3. 뉴스 원문과 질문을 입력한 뒤 검증을 시작합니다.

AI 모드에서도 최종 답변은 원문 인용을 코드가 다시 확인하고 검사 Agent가 통과시킨 항목만 사용합니다. 키는 파일에 저장하지 않습니다.

## 공개 사이트에 내 API 키 연결하기

친구들이 입력한 키 없이 AI 검증을 쓰게 하려면 Streamlit Cloud의 앱 설정에서 **Secrets**에 아래 한 줄을 추가합니다. API 키는 GitHub 파일이나 코드에 넣지 마세요.

```toml
OPENAI_API_KEY = "여기에_내_API_키"
```

서버 키가 등록되면 앱은 자동으로 서버 AI 모드를 사용하며, 브라우저 한 세션에서 실행할 수 있는 AI 검증 횟수를 5회로 제한합니다.

## 발표할 때 한 문장

> HALO는 모델이 그럴듯한 답을 자유롭게 완성하게 두는 대신, 작성·근거검사·출력을 분리하고 원문 근거가 확인된 항목만 답변에 통과시키는 fail-closed 구조입니다.

## 꼭 알아둘 한계

- 이 앱은 **원문과의 일치**를 확인합니다. 기사가 현실 세계에서 참인지까지 판정하지는 않습니다.
- “환각이 완전히 0%”라고 주장하면 안 됩니다. 이 데모는 원문 밖 내용을 줄이기 위한 검증 구조입니다.
- 기사 링크만으로는 작동하지 않습니다. 저작권 및 접근 문제 때문에 기사 텍스트를 직접 붙여 넣어야 합니다.
